# 📅 ระบบคลินิกวิชาการ — โรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย ปทุมธานี

## 🗂️ โครงสร้างไฟล์

```
ทำเวปคลีนิควิชาการ/
├── index.html          ← หน้าหลัก (redirect ไปหน้าตาราง)
├── schedule.html       ← หน้าตารางสอนเสริม (สาธารณะ)
├── attendance.html     ← หน้าสรุปการเข้าเรียน (สาธารณะ)
├── manual.html         ← หน้าคู่มือการใช้งานระบบ (สาธารณะ + ดาวน์โหลด PDF)
├── login.html          ← หน้าเข้าสู่ระบบ
├── teacher.html        ← ระบบครูผู้สอน (ต้อง login)
├── admin.html          ← ระบบ Admin (ต้อง login Admin)
├── 1_คู่มือการใช้งาน_ส่วนของนักเรียน.pdf
├── 2_คู่มือการใช้งาน_ส่วนของครูหอพัก.pdf
├── 3_คู่มือการใช้งาน_ส่วนของครูผู้สอน.pdf
├── คู่มือการใช้งาน_ระบบคลินิกวิชาการ_PCSHSPT.pdf (เล่มรวม 8 หน้า)
├── assets/
│   └── logo.png        ← โลโก้โรงเรียน
├── docs/               ← ไฟล์ HTML/PDF คู่มือฉบับเต็ม
├── css/
│   └── style.css       ← Design System CSS
└── js/
    ├── firebase-config.js  ← Config + ค่าคงที่
    ├── db.js               ← ฐานข้อมูล (localStorage / Firebase / Supabase)
    └── auth.js             ← ระบบ Login + เปลี่ยนรหัสผ่าน + Utilities
```

## 🚀 วิธีใช้งาน

1. **เปิดใช้งาน:** เปิดไฟล์ `schedule.html` ด้วยเว็บเบราว์เซอร์
2. **หน้าสาธารณะ:** ตารางสอนและสรุปการเข้าเรียน สามารถเปิดดูได้ทันทีไม่ต้องเข้าสู่ระบบ
3. **ครูผู้สอน:** คลิก "เข้าสู่ระบบ" → เลือกครูผู้สอน → ใส่รหัสผ่าน `98765432`
4. **Admin:** คลิก "เข้าสู่ระบบ" → เลือก Admin → username: `admin` / password: `Admin`

- ✅ ส่วนท้ายแสดง "โรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย ปทุมธานี"

### 2. หน้าสรุปการเข้าเรียน (attendance.html)

### 3. ระบบครูผู้สอน (teacher.html)
- ✅ ดูตารางสอนที่รับผิดชอบ
- ✅ แก้ไขเวลา ห้อง และสถานะการสอน

### 4. ระบบ Admin (admin.html)
- ✅ **ระบบเปลี่ยนรหัสผ่าน:**
  - เปลี่ยนรหัสผ่าน Admin (ต้องยืนยันรหัสผ่านเดิม)
  - กำหนดรหัสผ่านใหม่สำหรับครูผู้สอน
- ✅ **จัดการสัปดาห์:**
  - เพิ่ม/แก้ไข/ลบสัปดาห์
  - ตัวเลือก **"ไม่มีการเรียนการสอนทั้งสัปดาห์"** เพื่อนำไปแสดงในหน้าแรก
- ✅ **จัดการตารางคลินิก:**
  - CRUD ตารางสอนทุกระดับชั้น
- ✅ **จัดการครูผู้สอน:**
  - สรุปตาราง: ลำดับที่, รายชื่อครู, กลุ่มสาระ, จัดการ
  - ปุ่มดาวน์โหลดเทมเพลต Excel สำหรับครูผู้สอน (เปิดใน Excel ได้ทันที)
  - นำเข้าครูผ่านไฟล์ CSV/Excel
- ✅ **จัดการนักเรียน:**
  - ตัวกรองเลือกดูรายชั้น และ **รายห้อง**
  - ปุ่มดาวน์โหลดเทมเพลต Excel สำหรับนักเรียน (เปิดใน Excel ได้ทันที)
  - นำเข้าข้อมูลนักเรียนผ่านไฟล์ CSV/Excel พร้อมคำแนะนำ
- ✅ **จัดการเจ้าหน้าที่ (ใหม่):**
  - เมนู "เจ้าหน้าที่" ภายใต้ข้อมูลบุคลากร
  - ตารางสรุป: ลำดับที่, รายชื่อเจ้าหน้าที่, จัดการ
- ✅ **จัดการประกาศ และ Export ข้อมูลทั้งหมดเป็น JSON**

## ⚡ การเชื่อมต่อฐานข้อมูล Supabase Realtime (ใช้งานจริงทั้งโรงเรียน)

ระบบเชื่อมต่อกับฐานข้อมูล Cloud **Supabase PostgreSQL** แบบ **Real-time 24 ชม.**
- ครูบันทึกหรือเปลี่ยนห้อง/วิชา/นักเรียน ข้อมูลจะอัปเดตบนหน้าจอของนักเรียนและครูทุกคนทันที (< 0.1 วินาที)
- ไม่ต้องพึ่งพา Google Sheets อีกต่อไป
- มีระบบสำรองข้อมูลอัตโนมัติ และปุ่ม Export JSON ในเมนูตั้งค่า Admin

3. ระบบจะสร้างโดเมนให้ทันที เช่น `https://pccpt-clinic.vercel.app`

- คัดลอกไฟล์และโฟลเดอร์ทั้งหมดไปวางในโฟลเดอร์เว็บของโรงเรียน เช่น `/clinic/` บน Host เดิม
